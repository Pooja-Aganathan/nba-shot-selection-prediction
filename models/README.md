# Models Directory

This folder is intended for storing trained machine learning model artifacts.

Models used in this project include:

- Logistic Regression
- Random Forest
- XGBoost
- Semi-Supervised Learning Model

Model files such as:

- .pkl
- .joblib

can be stored here after training.

Trained model files are not included in this repository to maintain lightweight version control.

Models can be regenerated locally using the notebook or training pipeline.
